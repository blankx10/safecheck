关于安心查

很多人收到诈骗短信后不知道该不该点链接，也不敢把密码交给网站检查。安心查把常用自查做成免费、无需登录的小工具：规则引擎评估话术风险，浏览器内完成密码泄露查询，再用清单和情景题帮助加固账号。

技术栈

Python / Flask / SQLite 或 Postgres、Jinja2、HTMX、Tailwind CDN、zxcvbn、HIBP Pwned Passwords Range API。

开源

代码托管于 GitHub 公开仓库（部署后请替换为你的仓库地址）。

English overview

SafeCheck is a privacy-first, no-login web app that helps everyday users, students, and older adults check suspicious messages, test password exposure with k-anonymity, follow an account-hardening checklist, and practice scam scenarios. It never stores passwords or original message text, does not visit malicious links, and does not claim absolute security.
